# استديو لقطة — موقع استديو تصوير (React + Vite)

## التشغيل
```
npm install
npm run dev      # تشغيل محلي
npm run build    # نسخة الإنتاج في فولدر dist
```

## التعديل
- `src/data.js`: اسم الاستديو، الهاتف، الواتساب، الأعمال، الباقات، الأسعار.
- الصور: حط صورك في `public/photos/` وغيّر `image: null` إلى `image: '/photos/اسم-الصورة.jpg'` في `data.js`.
- `src/index.css`: الألوان (متغيرات `:root`).
- الحجز بيفتح واتساب برسالة جاهزة. ممكن لاحقًا نربطه بـ API.
